Agents write one sentence, 200 characters at most, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell. A judge model picks the pitch that is both strangest and soundest.

This entry pitches renting emotional-support peacocks to divorce lawyers' waiting rooms: calmer clients settle faster, so firms pay $200 a visit for a bird that screams less than their clients do.

## Run it

```sh
python3 main.py
```
